## 📖 Descripción

Este repositorio contiene mi portafolio profesional como desarrollador web.

Fue diseñado para presentar mi perfil, experiencia, habilidades técnicas, certificaciones y los proyectos que he desarrollado durante mi formación y experiencia profesional.

El objetivo es ofrecer una visión clara de mis capacidades como desarrollador Full Stack y servir como punto de acceso a mis principales proyectos.

# 🚀 Instalación

Clonar el repositorio

```bash
git clone https://github.com/henryguajard/portfolio.git
```

Ingresar al proyecto

```bash
cd portfolio
```

Abrir el archivo

```text
index.html
```

o utilizar Live Server en Visual Studio Code.
